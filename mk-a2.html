Македонски A2

Продовження курсу македонська: минулий і майбутній час, відмінки та форми, порівняння, складні речення, читання, листи. Натисни на слово чи фразу, щоб почути їх.

Розділ 0Як користуватися курсом

Рівень A2: ти вже вмієш знайомитися й говорити про себе, тепер вчишся розповідати про минуле, будувати плани, ввічливо просити, порівнювати й пояснювати причини. Вимова, сум, имам, член, числа й час розібрані в курсі A1.

Що вмітимеш наприкінці

  • розповісти про вчорашній день і відпустку (минулий час);
  • говорити про плани (ќе + теперішній);
  • ввічливо просити й мріяти (би сакал);
  • користуватися короткими формами займенників;
  • розрізняти вид дієслова;
  • порівнювати, будувати складні речення, написати лист.
Перевага українця. Вид дієслова, рід і числа в тебе вже «в голові». Відмінків у македонській нема, тож граматики менше, ніж в українській, але є кілька нових речей: член, да-конструкція й особливі минулі часи.
Хибні друзі. маса = стіл, стол = стілець, куќа = дім, час = година, година = рік, вечера = вечеря, леб = хліб, воз = потяг.

1.3. Перфект

Форма сум + дієприкметник на -л (работел / работела / работело / работеле) вживається, коли мовець сам не був свідком події, або розповідає про досвід: Била сум во Охрид. (Я була в Охриді.)

Вчера бев дома. | | Вчора я був удома. Вчера работев цел ден. | | Вчора я працював цілий день. Вчера напишав писмо. | | Вчора я написав листа. Видов еден филм. | | Я подивився фільм. Колку време имаше? | | Скільки у тебе було часу? Бил сум во Скопје. | | Я був у Скопʼє. Тие работеа цела ноќ. | | Вони працювали цілу ніч. Не бев дома. | | Мене не було вдома.
