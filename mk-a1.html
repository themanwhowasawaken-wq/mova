Македонски A1

Курс македонська для україномовних: вимова, граматика, словник за темами, діалоги, тексти й вправи. Натисни на слово чи фразу, щоб почути їх.

← ГоловнаРівень A2Вправи

Розділ 0Як користуватися курсом

Македонська — південнослов'янська мова, пишеться кирилицею. Українцеві читати легко, бо літери майже ті самі. Мова ближча до болгарської, ніж до сербської. Цей курс веде до рівня A1.

Що тобі допоможе

  • Кирилиця. Нових літер п'ять: ѓ, ќ, ѕ, ј, џ (є ще љ, њ).
  • Без відмінків. Замість них прийменники й порядок слів.
  • Член у кінці слова: книга → книгата (ця книга).
  • Нема інфінітива: замість нього да + теперішній час: Сакам да пијам кафе.
  • Наголос залежить від довжини слова (розділ 1).
Хибні друзі. маса = стіл, стол = стілець, куќа = дім, час = година, година = рік, вечера = вечеря, работа = робота й справа, леб = хліб, сирење = сир, воз = потяг, убав = гарний, кола = автомобіль.
Так і ні. да = так, не = ні. Македонці й болгари часом хитають головою навпаки: рух вправо-вліво може означати «так».

Як працювати

  1. Читай пояснення, натискай на слова, щоб почути їх.
  2. Роби вправи тут і на сторінці «Вправи».
  3. 20–30 хвилин щодня. План у розділі 9.

5.1. Конструкція «да + теперішній час»

Інфінітива немає. Замість нього — да + дієслово, узгоджене з особою.

Сакам да пијам кафе. | | Хочу пити каву. Мора да работам. | | Мушу працювати. Може ли да влезам? | | Можна ввійти? Знам да готвам. | | Вмію готувати. Сакаш ли да дојдеш? | | Хочеш прийти?
Прийменники замість відмінків. во = у/в, на = на, од = від/з, до = до, со = з, за = для/про. Живеам во Скопје. Одам во училиште. Книгата е на масата.

Модальне + да + теперішній.

Македонська не має інфінітива, тому після модального дієслова ставимо да і змінюємо дієслово за особою: Можам да дојдам. Мораш да работиш. Сака да пие кафе. Ввічливе бажання: Би сакал (m) / Би сакала (f) + да: Би сакал едно кафе.
