Slowenisch A2

Der nächste Schritt in Slowenisch: Vergangenheit und Zukunft, Konditional, Verbaspekt, Fälle, Steigerung, zusammengesetzte Sätze, Lesen und Briefe. Tippen Sie auf ein Wort oder einen Satz, um ihn zu hören.

Abschnitt 0So nutzt du den Kurs

Niveau A2: Du kannst dich schon vorstellen und über dich sprechen, jetzt lernst du, von der Vergangenheit zu erzählen, Pläne zu machen, höflich zu bitten, zu vergleichen und Gründe zu nennen. Aussprache, biti, imeti, Akkusativ und Lokativ, Zahlen und Uhrzeit stehen im Kurs A1.

Das kannst du am Ende

  • von gestern und vom Urlaub erzählen (Vergangenheit);
  • über Pläne sprechen (bom + Partizip);
  • höflich bitten und Wünsche äußern (rad bi, lahko bi);
  • Genitiv, Dativ und Instrumental benutzen;
  • den Verbaspekt unterscheiden;
  • vergleichen, zusammengesetzte Sätze bilden, einen Brief schreiben.
Dein Vorteil. Die Fälle kennst du aus dem Deutschen, auch Genus und Zahl. Du musst nur die slowenischen Endungen lernen und den Verbaspekt, den es im Deutschen nicht gibt.
Falsche Freunde. stol = Stuhl, miza = Tisch, hiša = Haus, veliko = viel, ura = Stunde, čas = Zeit, kruh = Brot, urad = Büro, vlak = Zug, kdo = wer.

Wortstellung.

Das Hilfsverb steht meist an zweiter Stelle: Včeraj sem bil doma. Steht kein anderes Wort davor: Delal sem. Verneinung: nisem delal.

Včeraj sem bil doma. | | Gestern war ich zu Hause. Prejšnji teden sva bili v Ljubljani. | | Letzte Woche waren wir (zwei Frauen) in Ljubljana. Brala sem knjigo. | | Ich (f) habe ein Buch gelesen. Kaj si delal? | | Was hast du gemacht? Nisem imel časa. | | Ich hatte keine Zeit. Šli smo na izlet. | | Wir sind auf einen Ausflug gefahren. Videla sem ga na postaji. | | Ich (f) habe ihn am Bahnhof gesehen. Ste že jedli? | | Habt ihr schon gegessen?

Zwei Möglichkeiten.

1) bom + Partizip auf -l (bom delal). 2) Das Präsens eines perfektiven Verbs hat Zukunftsbedeutung: Jutri napišem pismo. Das ist wie im Deutschen („Morgen schreibe ich den Brief“).

Abschnitt 3Konditional und höfliche Bitten

Konditional: bi (für alle Personen) + Partizip auf -l. bi ändert sich nicht: jaz bi, ti bi, mi bi.

Rad bi kavo. | | Ich hätte gern Kaffee. Rada bi šla na morje. | | Ich (f) würde gern ans Meer fahren. Lahko bi mi pomagal? | | Könntest du mir helfen? Ali bi lahko zaprli okno? | | Könnten Sie bitte das Fenster schließen? Če bi imel čas, bi šel. | | Wenn ich Zeit hätte, würde ich gehen. Rad bi rezerviral mizo. | | Ich würde gern einen Tisch reservieren.
Höflich. Lahko bi + Partizip ist die einfachste höfliche Form. Prosim macht die Bitte noch weicher. Männer sagen rad bi, Frauen rada bi.

Abschnitt 4Der Verbaspekt

Das ist neu für Deutschsprachige: imperfektiv — Vorgang oder Wiederholung, perfektiv — Ergebnis. Paare werden oft mit einem Präfix gebildet (pisati → napisati), manchmal mit einem Suffix (kupovati → kupiti).

Wann man ihn verwendet

  • Nach Präpositionen brez, do, iz, od, s/z (von einer Oberfläche), blizu, zaradi: brez sladkorja, do postaje, iz Ukrajine, od jutra do večera.
  • Mengen: kozarec vode, kos kruha, veliko ljudi, malo časa, nekaj denarja.
  • Verneinung: Nimam brata. Nimam časa.
Brez sladkorja, prosim. | | Ohne Zucker, bitte. Grem do postaje. | | Ich gehe bis zum Bahnhof. Kozarec vode, prosim. | | Ein Glas Wasser, bitte. Nimam sestre. | | Ich habe keine Schwester. Iz Ukrajine sem. | | Ich komme aus der Ukraine. Veliko dela imam. | | Ich habe viel Arbeit.

Präpositionen.

k / h + Dativ: k zdravniku, h Petru. z / s + Instrumental = „mit“: s prijateljem, z mamo. Verkehrsmittel: grem z avtobusom, z vlakom. Vor s, š, f, h, k, p, t, c, č schreibt man s, sonst z.

Pišem bratu. | | Ich schreibe meinem Bruder. Dam sestri darilo. | | Ich gebe meiner Schwester ein Geschenk. Grem k zdravniku. | | Ich gehe zum Arzt. Živim z mamo. | | Ich wohne mit meiner Mama. Govorim s prijateljem. | | Ich spreche mit einem Freund. Grem z vlakom. | | Ich fahre mit dem Zug.
